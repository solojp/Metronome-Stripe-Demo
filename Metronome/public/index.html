Metronome × Stripe

Usage-based billing, step by step

Follow along as this demo calls the Stripe and Metronome APIs in real time. Every request and response is shown exactly as the server sends it.

1

Create customer

Not started

Creates a Customer in Stripe, then creates a matching Customer in Metronome linked to that Stripe customer for billing.

POST /sign-up
2

Add payment method

Waiting

Starts a Stripe Checkout Session in setup mode so the customer can securely add a card.

POST /create-checkout-session
3

Set default payment method

Waiting

Marks the most recently added card as the customer's default for automatic invoice charging.

POST /set-default-payment-method
4

Create contract

Waiting

Creates a Metronome contract with a monthly subscription and recurring credits, billed through Stripe.

POST /create-contract
2

Create subscription

Waiting

Starts a Stripe Checkout Session in subscription mode, so the customer adds a card and subscribes to the base plan in one step.

POST /create-subscription
3

Create contract

Waiting

Creates a Metronome contract that only grants recurring credits, billed through Stripe — no embedded subscription.

POST /create-credits-contract
5

Send usage event

Waiting

Ingests a usage event into Metronome so it can be metered and billed on the next invoice.

POST /post-usage
